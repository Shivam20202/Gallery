### Requirements

- Node.js 18 or newer
- npm
- An internet connection, because the gallery loads images from Lorem Picsum

### Install dependencies

From the project folder, install the packages defined in `package.json`:

```bash
npm install
```

### Start the app locally

Run the Vite development script:

```bash
npm run dev
```

Vite will display the local address in the terminal. Open that address in a browser.

### Create a production build

```bash
npm run build
```
